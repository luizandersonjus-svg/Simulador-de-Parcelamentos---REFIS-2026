ARQUIVOS PARA SUBSTITUIÇÃO — Simulador de Parcelamentos REFIS 2026
================================================================

Versão atual (v4). Contém TODAS as mudanças deste atendimento:

1) CORREÇÃO — Valor "À vista" não era lido (bairro com "VISTA"
   confundia o parser).

2) LINHA TOTAL — última linha da planilha somando, por coluna, os
   valores exibidos (bate exatamente com =SOMA()).

3) CÉLULAS COM O VALOR DA PARCELA — cada coluna de plano mostra o
   valor da parcela como no PDF (ex.: coluna 8x mostra 1.055,85),
   em formato numérico, sem texto.

4) SEM OCULTAÇÃO — nenhum plano é mais ocultado, mesmo com parcela
   abaixo do mínimo (R$ 60,00 padrão, configurável no app).

5) AVISO EM VERMELHO — quando a parcela fica abaixo do mínimo:
   - no app: célula destacada em vermelho + seção "🔔 avisos";
   - no Excel: célula vermelha com comentário (passar o mouse) com a
     explicação e o máximo de parcelas possível mantendo o mínimo.

COMO APLICAR
------------

Opção A — GitHub pelo navegador (recomendado)
  1. Add file -> Upload files.
  2. Arraste parsers.py, app.py e excel_utils.py (substituem os atuais).
  3. Arraste também o test_parsers.py (de dentro da pasta tests) e o
     .gitignore, se ainda não existirem no repositório.
  4. Mensagem: fix: celulas com valor da parcela como no PDF
  5. Commit changes.

Opção B — Linha de comando (repositório clonado)
  Substitua parsers.py, app.py, excel_utils.py e, se quiser, os
  arquivos tests/test_parsers.py e .gitignore. Depois:
    git add -A
    git commit -m "fix: celulas com valor da parcela como no PDF"
    git push origin main

TESTES (opcional)
  pip install pytest
  python -m pytest tests/ -q      # deve mostrar: 8 passed

SEGURANÇA
  Não enviar PDFs com dados pessoais ao GitHub. Os testes usam
  apenas dados fictícios.
